```markdown
# TechPortal

## Mini Portal Responsivo com Bootstrap

Projeto desenvolvido para a disciplina Desenvolvimento Web III.

## Aluna

Mariane Laudelino De Lima

## Descrição

O TechPortal é um mini portal responsivo com o tema tecnologia.

O projeto foi desenvolvido utilizando HTML5, CSS3 e Bootstrap 5, com o objetivo de praticar a criação de layouts responsivos e a utilização de componentes do framework Bootstrap.

## Componentes utilizados

- Navbar
- Grid System
- Cards
- Carousel
- Modal
- Accordion
- Alert
- Badges
- Progress Bar
- Footer

## Responsividade

O projeto foi desenvolvido para funcionar adequadamente em diferentes tamanhos de tela:

- Computadores
- Tablets
- Celulares

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5

## Como executar o projeto

1. Faça o download ou clone do repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

Também é possível executar o projeto utilizando a extensão Live Server no Visual Studio Code.
```
